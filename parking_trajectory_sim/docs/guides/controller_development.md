# 制御器の追加方法

## 1. 基本方針

新しい制御器を試すたびにプロジェクト一式を複製する必要はありません。共通の軌道、車両モデル、シミュレーターを保ち、`controllers` 配下へ実装を追加します。これにより条件を揃えた比較ができます。

## 2. 追加手順

1. `TrajectoryController` を継承するヘッダーを `include/controllers` に追加する。
2. `computeCommand(const ControllerInput& input)` を `src/controllers` に実装する。
3. CMake のソース一覧へ追加する。
4. `main.cpp` で選択できるようにする。
5. 制御器単体テストと同一シナリオでの比較テストを追加する。
6. `docs/controllers` に符号、導出、パラメーター、限界を書く。

`ControllerInput` から、現在状態、時刻参照点、軌道全体、最近傍点番号を利用できます。単純な制御器は必要な項目だけを読み、位置基準の制御器は `ReferenceSearcher` で注視点を取得します。

## 3. 共通化する範囲

変更の中心は制御器です。軌道データ構造、キネマティックモデル、シミュレーション結果、CSV 保存は要求が変わらない限り共通利用します。MPC で予測モデルが必要になった場合も、実車相当のシミュレーションモデルと制御器内部の予測モデルは分けてください。
