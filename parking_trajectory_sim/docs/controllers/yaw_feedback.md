# 方位誤差フィードバック制御

## 1. この章の目的

曲率フィードフォワード制御へ方位誤差の補正を追加し、初期方位誤差をゼロへ近づけます。段階3では横偏差を直接補正しません。

## 2. 使用する記号

| 記号 | 意味 |
|---|---|
| $\psi_r$ | 参照方位角 [rad] |
| $\psi$ | 車両方位角 [rad] |
| $e_\psi$ | 方位誤差 [rad] |
| $K_\psi$ | 方位誤差ゲイン |
| $q$ | 進行方向。前進は$+1$、後退は$-1$ |
| $L$ | ホイールベース [m] |
| $\kappa_r$ | 参照曲率 [1/m] |
| $\delta$ | 前輪舵角 [rad] |

## 3. 方位誤差

車両が参照方位へ一致するために必要な回転量を「参照－現在」で定義します。角度境界をまたぐ場合も最短方向を選ぶため、式 (1) で$[-\pi,\pi]$へ正規化します。

**理論ID：`YAW-EQ-01`**

$$
e_\psi
=\operatorname{wrap}(\psi_r-\psi)
\tag{1}
$$

## 4. フィードフォワード舵角

目標曲率を実現する舵角は、キネマティック自転車モデルの関係から式 (2) です。

<a id="yaw-eq-02"></a>
**理論ID：`YAW-EQ-02`**

<a id="yaw-eq-02"></a>

**理論ID：`YAW-EQ-02`**

<a id="yaw-eq-02"></a>

**理論ID：`YAW-EQ-02`**

<a id="yaw-eq-02"></a>

**理論ID：`YAW-EQ-02`**

$$
\delta_{\mathrm{ff}}
=\arctan(L\kappa_r)
\tag{2}
$$

式 (2) は理想的な目標軌道を走るための舵角ですが、現在の方位誤差は見ていません。

## 5. 前進時の補正方向

方位誤差が正なら、車両は参照より右を向いているため、左へ操舵して車両方位を増やす必要があります。前進時の補正舵角を式 (3) とします。

<a id="yaw-eq-03"></a>
**理論ID：`YAW-EQ-03`**

<a id="yaw-eq-03"></a>

**理論ID：`YAW-EQ-03`**

<a id="yaw-eq-03"></a>

**理論ID：`YAW-EQ-03`**

<a id="yaw-eq-03"></a>

**理論ID：`YAW-EQ-03`**

$$
\delta_{\mathrm{fb}}=K_\psi e_\psi
\tag{3}
$$

$K_\psi$を大きくすると素早く補正しますが、大きすぎると過大操舵や振動の原因になります。本実験では$K_\psi=1.0$です。

## 6. 後退時に符号を反転する理由

キネマティックモデルのヨーレートは式 (4) です。

<a id="yaw-eq-04"></a>
**理論ID：`YAW-EQ-04`**

<a id="yaw-eq-04"></a>

**理論ID：`YAW-EQ-04`**

<a id="yaw-eq-04"></a>

**理論ID：`YAW-EQ-04`**

<a id="yaw-eq-04"></a>

**理論ID：`YAW-EQ-04`**

$$
\dot\psi=\frac{v\tan\delta}{L}
\tag{4}
$$

後退では$v<0$なので、同じ正の舵角を与えても方位変化は前進時と反対になります。そこで速度の進行方向を式 (5) で定義します。

<a id="yaw-eq-05"></a>
**理論ID：`YAW-EQ-05`**

<a id="yaw-eq-05"></a>

**理論ID：`YAW-EQ-05`**

<a id="yaw-eq-05"></a>

**理論ID：`YAW-EQ-05`**

<a id="yaw-eq-05"></a>

**理論ID：`YAW-EQ-05`**

$$
q=\begin{cases}
+1 & (v_r\ge 0)\\
-1 & (v_r<0)
\end{cases}
\tag{5}
$$

式 (3)へ$q$を掛けると、前進・後退のどちらでも誤差を減らす方向の補正になります。

**理論ID：`YAW-EQ-06`**

$$
\delta_{\mathrm{fb}}=qK_\psi e_\psi
\tag{6}
$$

## 7. 最終的な制御則

式 (2)のフィードフォワード舵角と、式 (6)の補正舵角を加えます。

**理論ID：`YAW-EQ-07`**

$$
\delta_{\mathrm{command}}
=\arctan(L\kappa_r)+qK_\psi e_\psi
\tag{7}
$$

速度指令は段階2と同様に参照速度をそのまま使用します。

$$
v_{\mathrm{command}}=v_r
\tag{8}
$$

## 8. 制御できるものとできないもの

式 (7)が使用する誤差は方位誤差だけです。そのため、初期方位誤差は補正できますが、横偏差や縦偏差をゼロにする制御則ではありません。

方位を修正する途中で車両位置も変わりますが、それは位置誤差を直接制御した結果ではありません。段階4で横偏差フィードバックを追加して比較します。

| 制御器選択 | `src/main.cpp` の `--controller yaw-feedback` |

## 10. 初心者向け確認ポイント

- 方位誤差ゼロなら、式 (7)はフィードフォワード制御と同じになります。
- 前進で正の方位誤差なら補正舵角は正です。
- 後退では同じ方位誤差でも補正舵角の符号が反転します。
- 方位誤差が収束しても、位置誤差が残ることがあります。

実装関数、変数、単体テストとの対応は[全体トレーサビリティ](../traceability.md#71-フィードフォワード方位横偏差)を参照してください。
