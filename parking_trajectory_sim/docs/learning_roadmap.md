# 学習ロードマップ

## 1. 現在地

段階1から段階15の横方向線形MPCまで完了しています。有限ホライズン予測、二次評価関数、舵角・操舵速度制約、Receding Horizonを実装済みです。次は舵角と加速度を同時最適化する縦横統合線形MPCです。

段階2では、既存のforward・reverse軌道へ横偏差のみ、または縦・横・方位の複合誤差を与え、フィードフォワード制御だけでは誤差を補正できないことを確認しました。実験条件と結果は[フィードフォワード制御の初期誤差比較](experiments/feedforward_initial_offset_comparison.md)にまとめています。

## 2. 推奨する学習段階

1. **完了**：フィードフォワードだけの理想追従を確認する。
2. **完了**：初期横偏差を与え、横偏差が補正されないことを確認する。
3. **完了**：方位誤差フィードバックを追加する。
4. **完了**：横偏差フィードバックを追加する。
5. **完了**：Pure Pursuit と Stanley を同じインターフェースで比較する。
6. **完了**：操舵角・操舵速度制約を導入する。
7. **完了**：操舵一次遅れを導入する。
8. **完了**：線形誤差モデルとLQRを学ぶ。
9. **完了**：積分器付きLQRを学ぶ。
10. **完了**：前進・停止・後退の状態管理を学ぶ。
11. **完了**：[車速状態と速度フィードバック](controllers/longitudinal_velocity_control.md)を導入する。
12. **完了**：[加減速度制約とジャーク制約](controllers/longitudinal_constraints.md)を導入する。
13. **完了**：[停止位置制御](controllers/stop_position_control.md)を学ぶ。
14. **完了**：[縦方向制御と横方向制御の協調](controllers/longitudinal_lateral_coordination.md)を学ぶ。
15. **完了**：[横方向の線形MPC](controllers/linear_mpc.md)を学ぶ。
16. **次の段階**：舵角と加速度を扱う縦横統合線形MPCへ拡張する。
17. オフセットフリーMPC、非線形MPCへ進む。

方位誤差制御と横偏差制御は、MPC の状態・誤差・符号・安定化の意味を小さな構成で理解できるため、MPC より先に実装するのが適切です。
